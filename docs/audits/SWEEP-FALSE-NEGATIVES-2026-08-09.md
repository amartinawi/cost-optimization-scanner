## Executive summary

The sweep confirms the verification's extrapolation: material false negatives exist across effectively every cohort. Beyond the ~20 Pass-3 items, the sweep surfaced (unique, post-dedup) roughly **5 CRITICAL, ~28 HIGH, ~40 MEDIUM** findings. Five systemic classes explain most of them:

1. **Dead evidence reads that silently disable whole levers.** A syntactically valid query returns empty on every real account and nothing looks different: sagemaker Invocations dimensioned by `EndpointName` alone (AWS publishes no such dimension set) ✓; bedrock CW `ModelId` fed a suffix-stripped id that is a price-table key, not a valid dimension value (agent); network_cost CE filtered on `USAGE_TYPE_GROUP="AWS Data Transfer"`, which is a SERVICE value, not a USAGE_TYPE_GROUP value — zero matches ever, corroborated in all 8 live scans ✓; mediastore `BucketSizeBytes`, which is an S3 metric, not MediaStore ✓; transfer CW metric names `BytesUploaded/BytesDownloaded` vs the real `BytesIn/BytesOut` (agent); quicksight gating on a boto3 method (`describe_spice_capacity`) that does not exist (agent). **Proposed lessons-file addition:** for every evidence read feeding a lever, ask "if this returned empty on every real account, would anything in the output look different?"
2. **CoH plumbing is partly wired to types AWS never emits.** ✓ Verified against the local botocore `cost-optimization-hub` model (25-value ResourceType enum): `RedshiftCluster`, `OpenSearchDomain`, `EksCluster`, `RdsDbCluster`, `EcsTask`, `EcsCluster` are NOT CoH types — those `type_map` keys can never match, so the redshift tab (CoH-only by design) is structurally $0 forever, and the opensearch/eks CoH buckets are permanently empty. Conversely, real types `AuroraDbClusterStorage`, `RdsDbInstanceStorage`, `MemoryDBCluster`, `DocumentDBCluster`, `SageMakerEndpoint`, `WorkSpaces`, `DynamoDbReservedCapacity`, `MemoryDbReservedInstances` have no bucket — AWS-computed dollars dropped. This also qualifies several of the original audit's CONFIRMED items ("CoH orphan bucket consumed"): the consuming code exists, but nothing can ever arrive.
3. **The C6 headroom ledger was per-call** — ec2 could spend the ceiling 5×, rds 2×, aurora a 3rd time off the same CE pool. **[FIXED]** on the branch (scan-scoped ledger in `commitment_coverage.py`).
4. **Counted flat factors and unit errors survive** in corners the remediation missed: App Runner memory `"2048"` parsed as **2048 GB** (1024× counted overstatement, `adapters/apprunner.py:57` ✓); ec2 Dedicated-tenancy lever counts flat 30% of the SHARED-tenancy price where the real delta is ~6.25% (agent, live SKUs); sagemaker multi-model consolidation counts flat 30% with no feasibility gate (agent); lightsail region-scales globally-flat rates — the whole tab, +8% to +25% by region, live-reproduced ✓; quicksight region-scales flat SPICE rates and counts bundled non-releasable capacity (agent).
5. **E1 enumeration-path gaps are near-universal**: outermost `except → ctx.warn` on `list_*` in lambda, step_functions, msk, cloudfront, lightsail, quicksight, transfer, monitoring/backup/route53, opensearch, redshift — AccessDenied reads as "no resources".
